# Ranger 单机实验异常等待恢复实施计划

> **For agentic workers:** 使用 superpowers:executing-plans，当前会话逐项实现并验证；保持现有dirty，不提交或启动真机。

目标：运行期异常暂停并等待原条件恢复，继续同一run/task；用户停止不自动恢复，配置/协议输入错误保留明确拒绝。保留安全阈值、动作终态和真实停稳证明、每观察点3次小角恢复预算。

1. 审计入口动态准备、探索/规划/观察/接近、动作及传感器超时的退出路径；读取Go2对应实现（不可达须明确）。
2. 添加先失败的回归：重新观察前停稳等待；健康丢失等待；异常重入不换task；保留扫描索引/预算/目标；旧动作未终态不重发；用户取消不恢复；入口准备和诊断状态。
3. 单机Ranger复用现有停止/动作跟踪，在同一实验中等待健康/代价地图/输入/停稳，失败重试用原有冷却参数，不放宽门限；保留Go2和协同恢复流程。已完成扫描覆盖保留。总体等待不因默认实验时限退出；局部动作/调用超时仍触发停止与重试。
4. 动作故障仅在可证明旧动作终态后清除可恢复锁存；无法确认远端动作或证据写入恢复时保持等待并显示原因，不能冒充恢复。
5. 诊断显示等待类别、原因、恢复状态；结果不虚报成功。入口动态条件改为等待，参数/资源配置错误仍拒绝。
6. 定向回归、独立只读审查、实际安装加载核对；更新交接和使用说明。真机行为待授权现场验证。
